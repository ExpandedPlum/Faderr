Welcome to Faderr

Connect Plex and Lidarr to get started. Last.fm is optional.

Login password

Anyone who can reach Faderr without a password can delete artists. You'll be asked for it by your browser; the username is faderr.

Set with FADERR_PASSWORD in .env.

Plex

Plex is configured in .env, so it's managed there.

Enter the server URL and token yourself

Lidarr

Lidarr is configured in .env, so it's managed there.

Last.fm optional

Used to pick each artist's most popular track and show bios. Without it, Faderr picks a random track. Get a free API key.

Set with LASTFM_API_KEY in .env.
